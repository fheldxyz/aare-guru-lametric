# aare-guru-lametric

![gif von Lametric mit Aare Anzeige](https://media.giphy.com/media/QZ1ZTQ0yNbIPM1tB7B/giphy.gif)

Ein kleines node.js Tool welches [express](https://www.npmjs.com/package/express) nutzt und die [aare.guru](https://aare.guru/) API (siehe [API](https://aareguru.existenz.ch/)) in eine API übersetzt, welche von [Lametric Time](https://lametric.com/) akzeptiert wird.

Die App ist im [Lametric Store](https://apps.lametric.com/apps/aare_temperatur_anzeige__daten_von_aare_guru_/8544) kostenlos verfügbar und wird mit [render](https://render.com/) ~~heroku~~ gehosted.
